Vibecoded LUT Converter. 

Converts cube to png, png to cube, cube to cube and png to png.

Supports PNG 512, 4096, both HALD and OBS GRID. 

Supports .cube. 

Also supports ZIP: throw in a ZIP with files, receive ZIP with same files converted. 
Supports archives with folders.

Just open in browser and it works. 

Programmers, you are very very welcome to make an online version, add Adobe .xmp support and anything else. 

I'm not a GitHub user, so it would be easier to make forks, just please send me a link if you make one. I'd very much like to have Adobe .xmp support.
