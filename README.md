# HTML Tools by Loxion

A collection of portable tools to use in browser. Simple design language, responsive UI, built-in manual. Every program is a single-file .HTML designed to work 100% autonomously. Carefully vibecoded.

---

## Tools Included

### LUT Converter
Converts `.cube`, `.png`, and `.3dl` LUTs in every direction.
* Supports batch converting.
* Supports converting `.zip` folders to `.zip` folders, preserving folder structure.
* Supports tunable dithering.

### LUT Inverter
Inverts `.cube`, OBS, Hald, and `.3dl` LUTs.
> **Note:** Output LUTs aren’t suitable for professional use, as they inevitably introduce tearing. Use the output LUT as a reference for reverse engineering.

### LUT Xerox
Advanced program to copy a grainy vignetted LUT from anywhere.

### HTML Packer
Packs multiple text files into a single `pack.txt`.
* **Supported extensions:** `.txt`, `.csv`, `.html`, `.css`, `.js`, `.json`, `.xml`, `.md`, `.php`, `.py`, `.yaml`, `.m3u8`
