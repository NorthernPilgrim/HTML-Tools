# HTML Tools by Loxion

> Lightweight, zero-dependency browser tools for LUT processing and file utility tasks.

`Single-File HTML` • `100% Offline / Autonomous` • `Responsive UI` • `Built-in Manual`

A collection of portable web tools built with a simple design language, carefully vibecoded.

## Tools Included

### LUT Converter
Converts `.cube`, `.3dl`, `.PNG` OBS Grid and Hald LUTs in every direction.
* Generate a clean PNG LUT.
* Batch converting.
* Converting `.zip` folders to `.zip` folders, preserving folder structure.
* Tunable dithering.

### LUT Inverter
Inverts `.cube`, `.3dl`, `.PNG` OBS Grid and Hald LUTs.
> **Note:** Output LUTs aren’t suitable for professional use, as they inevitably introduce tearing. Use the output LUT as a reference for reverse engineering.

### LUT Xerox
Advanced program to copy a grainy vignetted LUT from anywhere.

### HTML Packer + HTML Unpacker
Pack multiple text files into a single `.HTML`. Unpack them later. This tool is used to publish the release in a single file.
* **Supported extensions:** `.txt`, `.csv`, `.html`, `.css`, `.js`, `.json`, `.xml`, `.md`, `.php`, `.py`, `.yaml`, `.m3u8`
